# Steal a Drop (MVP)

Это **минимальный рабочий сайт**: страница + PvP 1v1 в реальном времени (дуэль “камень‑ножницы‑бумага”) через WebSocket.

Важно: “1 в 1 как bloxybet” — это **большой продукт** (аккаунты, экономика, платежи, анти‑абуз, юридические вопросы). Здесь сделана **база**, от которой можно развивать проект.

## Как запустить на своём ПК (самый простой способ)

1) Установи Node.js (LTS):  
- Сайт: `https://nodejs.org/`

2) В папке проекта выполни:

```bash
npm install
npm run dev
```

3) Открой в браузере:
- `http://localhost:3000`

Тест PvP: открой сайт в **двух вкладках**, подключись двумя никами, нажми “В очередь”, сделай ходы.

## Что где лежит

- `index.html` — страница (лендинг + UI арены)
- `styles.css` — стили
- `app.js` — клиент (WebSocket, очередь, ходы)
- `server.js` — сервер (выдаёт статику и делает PvP/матчи)

## Как выложить в интернет (хостинг + домен)

Ниже самый понятный путь, если ты “вообще ничего не знаешь”.

### 1) Купить домен

Домен покупают у регистратора (любого нормального):
- Namecheap
- Porkbun
- Reg.ru (если тебе удобно в РФ)

Пример домена: `stealadrop.com` или `stealadrop.gg`.

### 2) Выбрать где будет “жить” сайт (хостинг)

Так как тут есть WebSocket‑сервер, нужен хостинг, который умеет **Node.js**:
- Render
- Railway
- Fly.io
- VPS (например Hetzner/DigitalOcean) — чуть сложнее, но гибко

Проще всего начать с Render/Railway: подключаешь GitHub → выбираешь репозиторий → “Deploy”.

### 3) Подключить домен к хостингу (DNS)

Когда хостинг даст тебе адрес вида `something.onrender.com`, ты делаешь:

1) В панели регистратора (или Cloudflare) находишь **DNS**.
2) Добавляешь запись:
   - **CNAME** `www` → `something.onrender.com`
3) Для корня домена (`@`) обычно делают:
   - либо **A** запись на IP (если хостинг дал IP),
   - либо “ALIAS/ANAME” (если провайдер DNS поддерживает),
   - либо редирект с `@` на `www`.

Через 5–60 минут домен начнёт открываться.

### 4) HTTPS (замочек)

На большинстве хостингов HTTPS включается автоматически после подключения домена.

## Что делать дальше, чтобы было “как большой сайт”

Минимальный “план развития”:

1) **Аккаунты**
   - обычная регистрация или OAuth (Discord/Google/Roblox)
2) **База данных**
   - PostgreSQL (часто дают прямо в Render/Railway)
3) **Игровые режимы**
   - не RPS, а твоя механика PvP (тайминги, предметы, урон, арена и т.д.)
4) **Рейтинги/статистика**
   - матчи, победы, ELO/MMR
5) **Анти‑абуз**
   - лимиты, блокировки, защита от спама/ботов

Если планируешь **ставки/деньги/крипту**: заранее разберись с законами (лицензия, возрастные ограничения, KYC/AML) — это отдельный большой слой.
